# multi-city-transit-pipeline

A real-time transit analytics pipeline that aggregates GTFS and transit APIs from multiple cities into a unified schema to compare congestion and delays across transit systems.

## Planned Features

- Multi-city GTFS ingestion
- Unified schema normalization
- DuckDB analytics storage
- FastAPI service layer
- Strawberry GraphQL API
- Schema evolution handling
- Dockerized deployment

## Tech Stack

- Python
- DuckDB
- FastAPI
- Strawberry GraphQL
- Docker
